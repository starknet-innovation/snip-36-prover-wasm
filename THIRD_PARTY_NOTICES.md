# Third-party sources

This project adapts Apache-2.0 code from StarkWare's [sequencer](https://github.com/starkware-libs/sequencer), [proving-utils](https://github.com/starkware-libs/proving-utils), [stwo](https://github.com/starkware-libs/stwo), [stwo-cairo](https://github.com/starkware-libs/stwo-cairo), and [stwo-circuits](https://github.com/starkware-libs/stwo-circuits). Exact revisions are in `pins.json`; original notices remain in upstream checkouts and patch context. The portable compiler archive contains the pinned Cairo package and its package metadata.

The transaction hashing and submission behavior follows the [SNIP-36 prover backend](https://github.com/starknet-innovation/snip-36-prover-backend); this repository independently implements its SNIP-36 hash formula and daily browser harness. JavaScript cryptography uses @scure/starknet and its pinned @noble dependencies; browser automation uses Playwright. Their package licenses are distributed in node_modules by npm and listed by the packages' manifests.

Browser bindings are generated by wasm-bindgen. Release assets include the upstream proving and execution code under their respective licenses. This is an experimental integration, not an upstream endorsement or independent security audit.

The memory port uses implementation references from the Apache-2.0
[starknet-innovation/proving](https://github.com/starknet-innovation/proving)
fork. Exact commits, source jobs, patch digests, participant credit and credited
collaborators are retained in [the provenance ledger](docs/port/source-ledger.json).
The browser adaptations preserve the target's pinned protocol profile. Native
experiment results do not establish browser performance gains. Models are
recorded as execution provenance, not authors.

The CoinFlip contract and application flow are adapted from
`apps/coinflip`, `web/coinflip`, and `tests/contracts/src/lib.cairo` at the pinned
backend revision `4c8dfb1d0d63c47284e5da0ee1068415d47f9f78` (Apache-2.0).
The browser crypto bundle uses the already listed `@scure/starknet` package;
esbuild (MIT) is used only at build time.
